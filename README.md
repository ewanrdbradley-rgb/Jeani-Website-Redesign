# Jeani website redesign

The marketing site for Jeani, the personal health agent. Next.js App Router,
TypeScript, Tailwind v4.

The site is built around one idea: Jeani is different for every person. No two
dashboards on the site are ever the same, and a thin cobalt thread line draws
down every page with scroll, stitching the story together from the goal in the
hero to the closing call to action.

## Pages

- Home: cycling goal headline, goal cards that rebuild the page, three distinct
  phone dashboards, pinned belief band, proof row
- Product: pinned persona toggle, four feature blocks that follow the selection
- Science: the four-layer stack, Thorpe, the 11 percent stat, validation band
- Story: origin, founders, belief and vision
- Pricing: monthly and annual with a two-week free trial

## Brand

Bone `#EEEBE4`, deep cobalt `#102278`, bright blue `#0068B5`, Inter. Headlines
in Inter Black, sentence case. Photography from the Jeani library at golden
hour. Motion is fades only, 300 to 500ms ease-out, with reduced motion
respected throughout.

## Run

```
npm install
npm run dev
```
